## Граф

Вершина: любой .py в проекте, кроме файлов под test / tests / __tests__.

Ребро A -> B: в A есть import, который резолвится в файл B внутри репозитория.
Направление от зависимого к зависимости (A импортирует B, ребро A -> B).

Импорты через ast, resolve_import ищет module.py или package/__init__.py.
Внешние модули (stdlib, twisted и пр.) не добавляю.

Для impact дополнительно нужен обратный граф (кто импортирует данный файл).

## Сложность

V - вершины, E - ребра (в выводе stats пишется «ребер» без ё).

Построение графа: обход файлов + ast + списки смежности, O(V + E).
stats, impact, order: O(V + E).
cycles: итеративный DFS, по каждому ребру константная работа; обратное ребро ищется по словарю позиции на текущем пути (без path.index и без копирования path на каждом шаге). Обход O(V + E), плюс O(сумма длин найденных циклов) на запись списков.
Память O(V + E).
